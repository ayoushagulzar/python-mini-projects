# 🎮 Hangman Game

A console-based Hangman game built in Python, where the player attempts to guess a randomly selected word one letter at a time before running out of guesses.

--- 

## ✨ Features

-   Random word selection
-   Interactive letter guessing
-   Input validation
-   Prevents duplicate guesses
-   ASCII Hangman artwork
-   Tracks guessed letters
-   Win and lose conditions
-   Separate word-list module

--- 

## 🧠 Concepts Practiced

-   Functions
-   Loops
-   Conditional statements
-   Lists
-   Sets
-   Dictionaries
-   Tuples
-   String operations
-   `random` module
-   Custom modules and imports
-   Input validation
-   `__name__ == "__main__"`
